# 任务控制

## 超时与截图

面板中的“超时（毫秒）”会保存到状态文件，并同时用于 Playwright 的操作超时和页面导航超时。任务日志会记录实际生效的值。Debug 模式下，runner 会在关闭 Chromium 前尝试从仍打开的页面保存最后界面截图；成功任务标记为 success，异常任务标记为 failure。如果原页面已关闭，会搜索同一浏览器上下文中的其他页面。

“结算等待时间（分钟）”独立于 Playwright 超时。任务到达 checkout 并识别 Cancel 后，会保持浏览器开启等待该时间；默认值为 `0`，允许小数分钟。

FlareSolverr 的挑战处理仍使用 `VOXTRY_FLARESOLVERR_TIMEOUT_MS`，它是 solver 服务请求的独立超时，不受表单页面超时设置影响。

## Cancel 结果确认

支付 iframe 中的 Cancel 点击完成后，runner 会检查主页面和所有 iframe 的文本，确认订单错误结果页已经出现；只发生点击、隐藏控件或普通导航不会直接判定成功。当前确认条件为订单错误文案与“未扣款”或“Go back to plans”组合出现。首次点击后 3 秒仍无结果时，会补发一次强制点击或 DOM click，之后继续使用面板超时作为最终确认期限。

“任务结束时点击 Cancel”默认勾选。结算等待结束后，勾选时执行 Cancel 并确认错误结果页；取消勾选时直接关闭浏览器。Debug 模式会在关闭前保存最终支付页截图。

面板默认使用 `button[aria-label="Continue"]` 选择 checkout 中的 Continue，并使用 `input#btnCancel` 选择支付 iframe 中的 Cancel。runner 会在主页面和 iframe 中查找这些选择器；旧的 `button:has-text("Continue")` 与 `#btnCancel` 配置会在读取状态时自动迁移。

Cookie 弹窗在页面加载完成后可能延迟出现。runner 会等待最多 10 秒查找配置的 Cookie 选择器，并以“Accept essential cookies only”文案作为备用选择器；点击后才继续执行套餐步骤。

随机出生年份限制为 `2000` 至 `2004`，包含两端。

## 批次执行

“任务次数”表示本批次要消费的邮箱数量；“并发数”为 `1` 时按邮箱顺序串行执行，大于 `1` 时由多个 worker 并行执行。开始前会检查任务次数是否小于等于当前可用邮箱数量，检查失败时不会标记邮箱或创建任务记录。

每个邮箱会生成一条任务记录，记录邮箱、状态、时间和结果消息。任务完成、失败或停止都会更新记录和批次进度。任务记录支持在面板删除单条记录或清空全部记录。

任务记录位于邮箱队列下方，默认收起；点击“任务记录”标题可展开查看。Playwright 与代理池设置位于任务记录下方。

## 代理失败重试

启用“每次任务随机选择代理”后，每次任务会从当前批次的可用代理中随机取用。FlareSolverr 报告代理隧道或连接错误时，该代理会被当前批次临时拉黑，任务换用另一条代理重试一次；第二条代理仍连接失败才判定任务失败。批次结束后临时黑名单释放，不影响下一批次。

## 日志

日志默认自动滚动到底部。取消“自动滚动”后，轮询只更新内容，不会主动修改日志滚动位置；偏好保存在当前浏览器的本地存储中。
