# 随机生成与资料卡

面板顶部的“随机生成”页面用于创建临时填表资料，“填表”页面保留原有批量任务功能。面板登录后默认进入随机生成页并自动创建一张资料卡；从填表页切回随机生成页时也会自动创建一张新卡，重复点击当前页签不会重复创建。

点击“生成资料”会从当前邮编池随机选择一个邮编，并生成以下内容：

- 邮箱：空白
- 生日（PDF密码）：`DDMMYYYY`，年份限定为 `2000` 至 `2004`
- 名字、姓氏：分别从扩展的常见和少见姓名池中随机生成
- 地址：当前邮编池中的一条
- 密码、PIN码、密保答案：随机生成
- 号码：空白

生成的资料会立即写入 `data/state.json`。每个内容框都可以直接点击复制；“全部复制”会按固定顺序输出逐行文本，名字和姓氏合并为一行 `名字：名字 姓氏`，同时保留字段前缀，邮箱和号码等空字段只保留前缀。卡片名称可以通过铅笔按钮修改，卡片可单独删除；资料卡库支持保存最多 500 张卡片，并会在桌面端以多列紧凑卡片显示。

如果邮编池为空，生成操作会提示先录入邮编。生成资料不会消费邮箱队列，也不会启动填表任务。
